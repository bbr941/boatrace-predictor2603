# ウォークスルー: ボートレース自動通知ワーカー (`auto_trader.py`)

完全自動で稼働するバックグラウンド常駐型スクリプト [`auto_trader.py`](file:///d:/BOAT2512_AntiGravity_2_ana/auto_trader.py) の実装および検証が完了しました。

---

## 1. 実装された機能サマリー

### ① 日次スケジュール自動取得 & 5分前トリガー登録
- **公式連携**: `https://www.boatrace.jp/owpc/pc/race/index?hd=YYYYMMDD` より当日の全開催場をスクレイピング。
- **締切時刻パース**: 各場の `raceindex` より全12Rの締切時刻を取得。
- **5分前トリガー**: `締切時刻 - 5分` を算出し、`schedule` ライブラリへジョブ登録。
- **日次リフレッシュ**: 毎朝 `08:00` に当日の全場スケジュールを自動リフレッシュ登録。

### ② 黄金ベースライン推論エンジン (Quant Dual Engine)
- **水面適格判定**: 難水面/Cluster 1 (`[2, 3, 4, 14, 22]`: 戸田・江戸川・平和島・鳴門・福岡) を即時除外（0R参戦）。
- **欠場艇（出走除外）動的補正**: 欠場艇を自動検知し、出走艇数に応じた動的合成勝率・init_score・Benter確率展開（5艇立てなら60通り）を適用。
- **Gatekeeper**: `model_honmei.txt` (Platt Scaling) により本命1着確率 $P_1$ を評価。$P_1 \ge 0.7438$ (74.38%) 未満は即座に見送り。
- **Extractor & Benter**: `model_residual.txt` による残差予測と会場クラスタ $(d_2, d_3)$ パラメーターによる確率展開。
- **Optimizer**: $\text{EV} \ge 1.25 \land \text{Odds} \le 30.0$、固定ウェイト（単一レース上限5% = 5,000円、買い目上限2% = 2,000円、想定資金10万円、100円単位切り捨て）。

### ③ Discord Webhook 通知 (リッチ Embed)
- `.env` の `DISCORD_WEBHOOK_URL` を読み込み。
- **投資GOサイン** 点灯時のみ、以下の情報をリッチな Embed 形式で POST 送信：
  - 会場名・レース番号・締切時刻
  - Gatekeeper P1 信頼度 & 本命艇番 & 2位差
  - 会場クラスタ名
  - 推奨投資総額（資金配分比率）
  - 推奨買い目テーブル（買い目・推奨金額・実オッズ・EV・払戻見込）
  - 最高払戻金見込

## 3. 使用方法

### 🚀 バックグラウンド常駐起動
```powershell
python auto_trader.py
```

### 🧪 ドライラン（Discord送信なし・ログ出力のみ）
```powershell
python auto_trader.py --dry-run
```

### 🔍 単体レース即時テスト
```powershell
python auto_trader.py --test --venue 18 --race 10 --dry-run
```

### ⚙️ 設定（`.env`）
`.env` ファイルに Discord Webhook URL を設定します：
```env
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/your_webhook_id/your_webhook_token
```
