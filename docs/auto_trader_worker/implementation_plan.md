# 実装計画: ボートレース自動通知ワーカー (`auto_trader.py`)

## 目的と概要
本計画は、毎日自動で全開催場のレーススケジュールと締切時刻を取得し、**各レースの「締切5分前」に黄金ベースライン（Quant Dual Engine）推論を実行**して、投資GOサインが出た場合のみ **Discord Webhook に自動通知**する常駐型ワーカー `auto_trader.py` を実装するものです。

---

## 1. システム構成とワークフロー

```
[毎朝 08:00 (または起動時)]
       │
       ▼
[1. 日次スケジュール一括取得 (fetch_daily_schedules)]
  - https://www.boatrace.jp/owpc/pc/race/index?hd=YYYYMMDD より開催場一覧を取得
  - 各会場の raceindex より全12Rの「締切時刻」を抽出
  - 締切5分前（Deadline - 5min）の実行時刻を算出し、`schedule` にジョブ登録
       │
       ▼
[2. 常駐待機ループ (Main Loop)]
  - `schedule.run_pending()` + `time.sleep(1)` で待機
       │
       ▼ (指定時刻: 締切5分前 到来)
[3. レース自動評価トリガー (process_race_target)]
  ├─ ① 水面適格判定: Cluster 1 (戸田02, 江戸川03, 平和島04, 鳴門14, 福岡22) なら即時スキップ
  ├─ ② データ取得: 出走表・展示タイム・直前オッズ (odds3t) をスクレイピング
  ├─ ③ 特徴量生成 & 欠場艇（出走除外）動的補正
  ├─ ④ Gatekeeper推論: `model_honmei.txt` (Platt Scaling) -> P1 >= 0.7438 (74.38%) 判定
  │     └─ 未達ならログ出力して終了 (No Bet)
  ├─ ⑤ Extractor & Benter確率展開: `model_residual.txt` + `OddsNormalizer` -> クラスタ別(d2, d3)展開
  └─ ⑥ PortfolioOptimizer: EV >= 1.25, Odds <= 30.0, 固定ウェイト上限5% (買い目2%) で資金配分算出
       │
       ▼ (買い目選出: 🚀 投資GOサイン)
[4. Discord Webhook 通知 (send_discord_notification)]
  - `.env` から `DISCORD_WEBHOOK_URL` を読み込み
  - リッチな Embed メッセージ（会場・R・締切・P1信頼度・買い目・オッズ・EV・推奨金額・払戻見込）を POST 送信
```

---

## 2. 実装詳細

### A. スケジューリング (`schedule` ライブラリ)
- 起動時に当日（`today`）の未完了レースを即座に登録。
- 毎日 08:00 に翌日/当日の全場スケジュールを自動リフレッシュ登録。
- 締切5分前が既に過ぎているレースはスキップ。

### B. 黄金ベースライン推論パイプライン
- **Cluster 1 難水面除外**: 会場コード `2, 3, 4, 14, 22` は即時除外。
- **Gatekeeper**: $P_1 \ge 0.7438$（バックテスト上位15%境界値）。
- **欠場艇対応**: 出走除外艇がいる場合でも、出走艇数に応じた動的合成勝率・ロジット変換・Benter展開（5艇立てなら60通り）を適用。
- **Optimizer**: $\text{EV} \ge 1.25 \land \text{Odds} \le 30.0$、固定ウェイト（単一レース上限5% = 5,000円、買い目上限2% = 2,000円、想定バンクロール10万円、100円単位切り捨て）。

### C. Discord Webhook 通知 (Embed 仕様)
- **タイトル**: `🚀 【投資GOサイン】徳山 10R（締切 15:25 / 発走5分前）`
- **カラー**: エメラルドグリーン (`0x00E676`)
- **フィールド**:
  - `🛡️ Gatekeeper信頼度`: `82.4% (1号艇)`
  - `🏟️ 会場クラスタ`: `Cluster 0 (イン超強水面)`
  - `💰 推奨総投資額`: `3,200円 (配分比率 3.2%)`
  - `🎯 推奨買い目一覧`:
    ```
    ・1-2-3: 1,200円 (Odds 12.4倍 / EV 1.48 / 払戻 14,880円)
    ・1-2-4: 1,000円 (Odds 18.2倍 / EV 1.35 / 払戻 18,200円)
    ・1-3-2: 1,000円 (Odds 21.0倍 / EV 1.28 / 払戻 21,000円)
    ```

### D. CLI オプション
- `python auto_trader.py` : 通常常駐稼働モード
- `python auto_trader.py --test --date 20260829 --venue 18 --race 10` : 指定レースの即時単体テスト
- `python auto_trader.py --dry-run` : Discord送信を行わずコンソール出力のみで稼働

---

## 3. 検証計画

1. **スケジュール取得機能のテスト**:
   - 本日のボートレース公式から全会場・全12Rの締切時刻が正確にパースされるか検証。
2. **単体推論テスト (`--test`)**:
   - 実在レースを指定して即時実行し、水面判定、Gatekeeper判定、Benter展開、資金配分が正常に行われるか検証。
3. **Discord Webhook 送信テスト**:
   - Webhook URL またはモック送信により、正しく Embed ペイロードが生成・送信されるか検証。
