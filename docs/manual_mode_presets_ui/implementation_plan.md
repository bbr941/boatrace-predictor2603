# 実装計画: Streamlitアプリ マニュアル推論の3モード切替UI実装

## 目的と概要
`app_boatrace.py` および `boatrace-v3-predictor/app_v3.py` を改修し、手動推論（マニュアルプレイモード）においてユーザーの目的に合わせた以下の**3つのプリセットモード**をワンクリックで切り替えられる機能を実装します。

1. **🏆 ① ガチ投資（黄金ベースライン）**: 従来の厳格な数学的エッジ抽出（Gatekeeper $P_1 \ge 0.7438$、難水面除外、$\text{EV} \ge 1.25$）。
2. **🍿 ② エンタメ（多参戦・微バリュー）**: ほぼ全レースに参加しつつ、最低限のエッジ（$\text{EV} \ge 1.05$）を狙う高回転設定。
3. **🎯 ③ 的中特化（確率上位5点買い）**: オッズやEVを完全無視し、AIが算出したBenter展開確率の「上位5点」を100円均等配分で抽出する的中重視設定。

ダッシュボード（閲覧モード）の機能は完全に維持し、マニュアル推論結果も Supabase にモード情報付きで自動保存されます。

## 1. プリセットモード仕様詳細

| 項目 | 🏆 ガチ投資（黄金ベースライン） | 🍿 エンタメ（多参戦・微バリュー） | 🎯 的中特化（確率上位5点買い） |
|---|---|---|---|
| **Gatekeeper 閾値** | $P_1 \ge 0.7438$ (上位15%) | $P_1 \ge 0.0$ (実質足切りなし) | $P_1 \ge 0.0$ (実質足切りなし) |
| **難水面（Cluster 1）除外** | **有効** (即時スキップ) | **無効** (全水面参戦) | **無効** (全水面参戦) |
| **最小期待値 ($\text{EV}$)** | $\text{EV} \ge 1.25$ | $\text{EV} \ge 1.05$ | 制限なし (全買い目対象) |
| **最大オッズ上限** | $\text{Odds} \le 30.0$ | $\text{Odds} \le 100.0$ | 制限なし |
| **買い目選出ロジック** | SLSQP 最適化 (固定5% / ケリー) | SLSQP 最適化 (固定5% / ケリー) | **Benter 確率降順 TOP 5** |
| **投資金額配分** | 最適化ウェイト (上限2,000円) | 最適化ウェイト (上限2,000円) | **均等 100円 × 5点 (計500円)** |
| **保存ステータス** | `investment_go` / `gatekeeper_skipped` | `entertainment_go` / `no_value_bets` | `hit_focused_go` |
| **UI テーマカラー** | エメラルドグリーン (Emerald) | アンバーオレンジ (Amber) | ネオンパープル (Purple) |

## 3. 検証計画

1. **構文チェック**:
   - `python -m py_compile app_boatrace.py boatrace-v3-predictor/app_v3.py db_manager.py` で構文エラーがないことを確認。
2. **モード別単体テスト**:
   - ① ガチ投資モード: Cluster 1 会場で即時スキップ、通常水面で $P_1 < 74.38\%$ 時に足切りされることを確認。
   - ② エンタメモード: Cluster 1 会場でも推論が実行され、$\text{EV} \ge 1.05$ の買い目が選出されることを確認。
   - ③ 的中特化モード: 120通りの Benter 展開確率から TOP 5 の買い目が抽出され、100円均等配分（計500円）でテーブル表示 & Supabase 保存されることを確認。
3. **ダッシュボード連携確認**:
   - モード別推論結果が Supabase に保存され、ダッシュボード側で正しく集計・表示されることを確認。
