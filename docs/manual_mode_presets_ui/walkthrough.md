# 変更完了書 (Walkthrough): Streamlitアプリ マニュアル推論の3モード切替UI実装

手動推論（マニュアルプレイモード）において、ユーザーの目的に合わせた**3つのプリセットモード（ガチ投資・エンタメ・的中特化）**をワンクリックで切り替えて推論・資金配分・DB保存できる機能を実装・検証しました。

---

## 1. 実装された3つのプリセットモード

| モード名 | 主なパラメーター・ロジック | 適用用途・特徴 |
|---|---|---|
| **🏆 ① ガチ投資（黄金ベースライン）** | ・Gatekeeper $P_1 \ge 0.7438$<br>・難水面（Cluster 1）除外 = ON<br>・$\text{EV} \ge 1.25$, $\text{Odds} \le 30.0$<br>・固定ウェイト上限 (Max 5% / 2%) | 過去5,000レース検証で回収率108%超を実証した厳格設定。確固たる数学的エッジのある本命レースのみに絞り込んで投資。 |
| **🍿 ② エンタメ（多参戦・微バリュー）** | ・Gatekeeper $P_1 \ge 0.0$ (足切りなし)<br>・難水面（Cluster 1）除外 = OFF (全水面参戦)<br>・$\text{EV} \ge 1.05$, $\text{Odds} \le 100.0$<br>・固定5% / ケリー最適化 | ほぼ全レースに参加し、少しでも期待値がある買い目（微バリュー）を幅広く拾って楽しむ高回転設定。 |
| **🎯 ③ 的中特化（確率上位5点買い）** | ・Gatekeeper $P_1 \ge 0.0$<br>・難水面除外 = OFF<br>・オッズ/EVフィルター バイパス<br>・**Benter 展開確率降順 TOP 5**<br>・**均等配分 100円 × 5点 (計500円)** | オッズやEVを気にせず、AIが予測した展開確率の「上位5点」を100円均等配分で購入する的中重視設定。 |

## 2. 変更ファイル詳細

### 1) [`app_boatrace.py`](file:///d:/BOAT2512_AntiGravity_2_ana/app_boatrace.py) / [`boatrace-v3-predictor/app_v3.py`](file:///d:/BOAT2512_AntiGravity_2_ana/boatrace-v3-predictor/app_v3.py)
- **サイドバー**:
  - `🎯 プレイモード選択 (Preset)` ラジオボタンを追加。
  - 選択したモードに応じて、Gatekeeperスライダーのデフォルト値・難水面スキップ・EV閾値・オッズ上限・的中特化用の点数/金額スライダーが自動で切り替わります。
- **推論ロジック**:
  - `hit_focused` モード時は全120通りの Benter 展開確率から上位N点（デフォルト5点）を抽出して100円均等配分。
  - `honmei_quant` / `entertainment` モード時は設定された EV 閾値で SLSQP 最適化を実行。
- **UI 表示**:
  - 推論結果サマリー上部に各モード専用のカラーバッジ（`🏆 ガチ投資`, `🍿 エンタメ`, `🎯 的中特化`）を表示。
  - 履歴テーブルにも `🍿 エンタメGO`, `🎯 的中特化GO` のバッジ表示を追加。

### 2) [`db_manager.py`](file:///d:/BOAT2512_AntiGravity_2_ana/db_manager.py)
- `get_dashboard_stats()` および `get_all_predictions_with_bets()` において、`entertainment_go`, `hit_focused_go` を含む全GOサインステータスを正しく集計・抽出できるようにクエリを更新。
