# 実装計画: 的中特化モードの動的ダッチング・トリガミ回避実装

## 目的と概要
`app_boatrace.py` および `boatrace-v3-predictor/app_v3.py` の「🎯 ③ 的中特化モード」において、固定100円均等買いから、**累積確率50%カバレッジ**と**オッズ連動ダッチング（資金配分）＋トリガミ（ガミり）自動回避ループ**を組み合わせた高度な動的配分ロジックへと改修します。

---

## 1. 改修仕様詳細

### ① UI 追加（サイドバー）
- 的中特化モード選択時のみ、以下の予算設定スライダーを表示：
  - **1レースあたりの予算**: デフォルト `1,000円`（設定範囲: 300円 〜 10,000円、100円刻み）。

### ② 動的買い目選定ロジック（カバレッジ制御）
1. 全120通りの Benter 予測確率 $P_i$ を降順ソート。
2. 有効オッズ（$\text{Odds} > 1.0$）を持つ買い目を上位から順に追加。
3. 累積確率 $\sum P_i \ge 0.50$ (50%) に達するか、最大 **8点** に達するまでリストを抽出（最低 2点）。

### ③ トリガミ回避ループ & ダッチング配分
1. **オッズ逆数和判定**: $S = \sum_{i} \frac{1}{\text{Odds}_i}$ を計算。
2. **トリガミ回避ループ**: $S \ge 0.95$ の場合、リスト末尾（確率最下位）の買い目を1つ削除し $S$ を再計算（リスト長が2点になるまで反復）。
3. **ダッチング配分**:
   $$\text{raw\_amount}_i = \text{予算} \times \frac{1 / \text{Odds}_i}{S}$$
   これを100円単位に四捨五入（最低100円）。
4. **最終トリガミ検証 & 微調整**:
   - 総投資額 $T = \sum \text{amt}_i$ に対し、各買い目の払戻 $\text{amt}_i \times \text{Odds}_i \le T$ となる（ガミる）買い目がある場合、配分を+100円微調整するか、解消困難な場合は最下位を削除して再計算。

### ④ 出力 & DB保存
- 推奨買い目テーブルに各買い目の配分金額、オッズ、払戻見込額、EV、確率を表示。
- Supabase の `race_predictions`（status: `hit_focused_go`）および `recommended_bets` へ正しく保存。
