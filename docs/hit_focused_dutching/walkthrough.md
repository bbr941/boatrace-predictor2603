# 変更完了書 (Walkthrough): 的中特化モードの動的ダッチング・トリガミ回避実装

Streamlit アプリ（[`app_boatrace.py`](file:///d:/BOAT2512_AntiGravity_2_ana/app_boatrace.py) / [`app_v3.py`](file:///d:/BOAT2512_AntiGravity_2_ana/boatrace-v3-predictor/app_v3.py)）の「🎯 的中特化モード」において、従来の固定100円均等配分から、**累積確率50%カバレッジ抽出**と**オッズ逆数連動ダッチング資金配分＋トリガミ（ガミり）自動回避ループ**を統合した動的配分アルゴリズムを実装・検証しました。

---

## 1. 実装された機能詳細

### ① UI 追加（予算スライダー）
- サイドバーで「🎯 的中特化（動的ダッチング・トリガミ回避）」を選択した際、**「1レースあたりの予算（デフォルト: 1,000円、範囲: 300円〜10,000円、100円単位）」**を設定できるスライダーを追加しました。

### ② 動的買い目選定ロジック（累積確率 50% & 最大 8点）
1. 全120通りの Benter 予測確率 $P_i$ を降順ソート。
2. 有効オッズ（$\text{Odds} > 1.0$）を持つ買い目を上位から順に追加。
3. 累積確率 $\sum P_i \ge 0.50$ (50%) に達するか、最大 **8点** に達するまでリストを動的抽出（最低 2点）。

### ③ トリガミ回避ループ & 100円単位ダッチング資金配分
1. **オッズ逆数和判定**: $S = \sum_{i} \frac{1}{\text{Odds}_i}$ を計算。
2. **事前トリガミ回避ループ**: $S \ge 0.95$ の場合、リスト末尾（確率最下位）の買い目を1つ削除して $S$ を再計算（リストが2点になるまで反復）。
3. **ダッチング配分**:
   $$\text{raw\_amount}_i = \text{予算} \times \frac{1 / \text{Odds}_i}{S}$$
   100円単位に四捨五入（最低100円）。
4. **事後トリガミ検証 & 微調整ループ**:
   - 総投資額 $T = \sum \text{amt}_i$ に対し、各買い目の払戻 $\text{amt}_i \times \text{Odds}_i \le T$ となる（ガミる）買い目がある場合、配分を+100円微調整するか、解消困難な場合は最下位を削除して再計算。
   - **どの買い目が的中しても必ず純利益がプラス（純利益 $> 0$）**になることを保証。

### ④ UI 表示 & DB 保存
- サマリーカードに見込払戻レンジ（例: `2,600 〜 2,760 円`）と最低純利益（例: `+800 円`）を表示。
- 結果テーブルに各買い目の配分金額、Benter確率、オッズ、払戻見込額に加え、**「純利益 (円)」**列を新設。
- Supabase の `race_predictions`（status: `hit_focused_go`）および `recommended_bets` へ正しく保存。

  ```
    1-3-2: 200円 @ 12.5倍 -> 払戻: 2,500円 (純利益: +1,500円)
    1-3-4: 100円 @ 18.0倍 -> 払戻: 1,800円 (純利益:   +800円)
  ```
  すべての買い目でトリガミなく、的中時に均等なプラスリターンが得られることを確認しました。
